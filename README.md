## Running Locally

No build tools or dependencies needed — it's plain HTML/CSS/JS.

```bash
git clone https://github.com/naziyagouri824-crypto/<this-repo-name>.git
cd <this-repo-name>
```

Then just open `index.html` in your browser (or use the VS Code "Live Server" extension for auto-reload while editing).
